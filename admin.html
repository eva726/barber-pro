💈 BARBER PRO — Administration

Accès protégé par GitHub. Cette page est visible publiquement, mais seules les personnes disposant d'un jeton GitHub autorisé peuvent publier des modifications. Ne communiquez jamais votre jeton. Aucun mot de passe n'est inclus dans le site. Le jeton reste uniquement en mémoire pendant cet onglet.

1. Autorisation de publication

Créez un fine-grained personal access token sur GitHub, limité au dépôt eva726/barber-pro, avec la permission Contents: Read and write. Collez-le ici uniquement sur votre propre ordinateur. Ne le transmettez à personne.
